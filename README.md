# Mon écosystème numérique de thèse

## Sujet de recherche
Évaluation de la santé sexuelle des femmes pendant la grossesse et le post-partum.

## Objectif
Mettre en place un environnement numérique permettant de gérer les références scientifiques, les documents de recherche et la traçabilité du projet.

## Outils utilisés
- ORCID : identité numérique du chercheur.
- Zotero : gestion bibliographique.
- DMP : plan de gestion des données inspiré de DMP OPIDoR.
- GitHub : suivi des versions et organisation du projet.

## Organisation du dépôt
- bibliographie/ : références BibTeX.
- dmp/ : plan de gestion des données.
- ia/ : charte d'utilisation de l'intelligence artificielle.
- tests/ : documentation des vérifications.

## Confidentialité
Aucune donnée individuelle de santé ou information permettant d'identifier les participantes ne doit être publiée dans ce dépôt.
